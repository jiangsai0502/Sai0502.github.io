         3. Crypto Sim：数字货币的模拟账户链接，好像是没有延迟的。
         4. Binance：币安的数据源连接好像也没有延迟。
      2. 自己申请的数据源
         1. 白嫖Rithmic：见 veilflow
         2. 购买defeed：
   4. 学习技巧：「有道词典」，截屏翻译

      2. 左侧指标列表 Volume Analysis 
         1. Volume Profile & TPO（常用）：手动选中任意范围，背景上展示其 VP
         2. Fixed Volume Profile & TPO（不常用）：展示最近1个指定周期的 VP
         3. Anchored Volume Profile & TPO（不常用）：圈定任意范围，屏幕左侧/右侧展示其 VP

         5. Visualization：Profile. Colors → Profile. Colors：蓝色
         6. Visualization：Profile. Colors → Visualization Mode可视化模式：Bars条形图
         7. Visualization：Profile. Colors → Gradient渐变：勾选

5. **下单（下面的不准，要单独找教程）**

   1. 调出交易栏：图标右键 → Chart Trader
   2. 交易栏
      1. 订单管理
         - Clear Bid：关闭限价买单挂单
         - Clear Ask：关闭限价卖单挂单
         - Clear All：关闭所有限价挂单
         - Close：平仓 / 关闭所有订单
         - 反向交易：平仓同时，自动下反向市价单
      2. 退出策略：自动止盈止损

         1. 点击 ▲ 打开设置 → 选择策略类型（最常用：固定止盈止损）
         2. 示例：止盈 30 Tick，止损 10 Tick
         3. 特性：
            - 下市价单成交后，自动挂上止盈止损
            - 下限价单成交后，才会显示并挂上止盈止损
            - 可手动拖动止盈止损价位调整
            - 平仓后，对应的止盈止损自动取消
      3. 图表交易
         - 默认关闭，可开启后在 K线图上点击 `Buy` / `Sell` 下单
         - 操作较麻烦，一般不使用
      4. 订单有效期
         - GTC（Good Till Cancelled）：订单一直有效，必须手动平仓，否则永久存在
         - Day：当天有效，美国市场收盘后自动平仓所有单（含浮动盈亏、限价单）
      5. 账户选择
         - `Demo`：软件自带模拟账户
         - 下方：实盘期货账户（需提前开户并连接）

6. 订单轨迹

   ```
   左数字  ×  右数字
   (卖方)     (买方)
   ```

   | 位置         | 代表方向     | 具体含义                                             |
   | ------------ | ------------ | ---------------------------------------------------- |
   | **右边数字** | **主动买**   | 买方主动吃掉卖方的**限价挂单**，即主动买入成交的数量 |
   | **左边数字** | **主动卖方** | 卖方主动吃掉买方的**限价挂单**，即主动卖出成交的数量 |

   | 颜色         | 含义                                                         |
   | ------------ | ------------------------------------------------------------ |
   | **黑色数字** | 该价位买卖双方成交量**相对均衡**，力量对比不明显             |
   | **红色数字** | 该价位成交量**大于前一个价位的 2 倍以上**，表示该方向力量突然放大 |

   ## 三、失衡（Imbalance）

   ### 3.1 核心逻辑：斜对角对比
   > **关键：不是横向对比，而是斜对角对比**

   ```
           卖 3
         卖 2   买 3
       卖 1   买 2
             买 1
   ```
   - 每个价位的买方成交量，与**斜对角的卖方成交量**进行对比
   - 而非同一水平线上的左右对比

   ### 3.2 失衡的判定标准

   | 类型             | 判定条件                                                   | 视觉表现             |
   | ---------------- | ---------------------------------------------------------- | -------------------- |
   | **2 倍失衡**     | 某价位成交量 > 前一位的 2 倍                               | 数字变**红色**       |
   | **3 倍买方失衡** | 连续 3 个以上价位，买方成交量 **3 倍于**斜对角的卖方成交量 | 形成连续的买方力量带 |
   | **3 倍卖方失衡** | 连续 3 个以上价位，卖方成交量 **3 倍于**斜对角的买方成交量 | 形成连续的卖方力量带 |

   ### 3.3 失衡的实战意义
   - **买方失衡带**：代表买方在该区域**主动进攻非常凶猛**，大量吃掉卖方挂单，普通 K 线完全看不到这一信息
   - **卖方失衡带**：同理，代表卖方抛压集中爆发

   ## 四、POC（Point of Control / 控制点）

   ### 4.1 定义
   - **黑框标出的价位**，每根 K 线都有且只有一个
   - 代表该 K 线时间周期内，**成交量最大的价位**
   - 该价位的成交量**远大于**其他所有价位

   ### 4.2 POC 的实战解读

   POC 位置与收盘价的关系，可判断多空动能强弱：

   | 场景         | POC 位置           | 收盘价位置         | 含义                                                         |
   | ------------ | ------------------ | ------------------ | ------------------------------------------------------------ |
   | **强势多头** | 下影线附近（偏低） | 远离 POC，收在高位 | 下方成交最多，但价格被强行推到高位 → **多头控盘极强**，可能是反转信号 |
   | **强势空头** | 上影线附近（偏高） | 远离 POC，收在低位 | 上方成交最多，但价格被压到低位 → **空头控盘极强**，下跌趋势确认 |
   | **震荡平衡** | 接近收盘价         | 与 POC 距离近      | 多空力量相对均衡，POC 成为短期价值共识区                     |

   ---

   ## 五、一句话总结

   > **传统 K 线告诉你"价格去了哪里"，订单轨迹告诉你"价格是怎么去那里的、谁主导了那里"。**

   - **右边红字** → 买方发力
   - **左边红字** → 卖方发力  
   - **斜对角 3 倍连续** → 失衡带（压力/支撑/突破点）
   - **黑框 POC** → 该 K 线的核心成交区，结合收盘价判断多空强弱
