## 第六期：交易功能详解

### 6.1 两种交易方式

| 方式                       | 适用人群         | 说明                                                         |
| -------------------------- | ---------------- | ------------------------------------------------------------ |
| **① 软件内直接交易**       | 有美国期货账户者 | 需香港卡+护照开户，软件本身就是交易软件                      |
| **② 当看盘工具 + MT4交易** | 国内大多数交易者 | 在 ATAS 看盘分析，在 MT4 下单交易（价格有几美金差价，K线形态一致） |

### 6.2 交易盘面（Chart Trader）

**基础下单**
- **Buy / Ask**：市价买单 / 市价卖单
- **数量设置**：默认下单手数
- **显示方式**：金额（最常用）、百分比、Tick级别、不显示

**订单管理**
- **Clear Bid**：关闭限价买单挂单
- **Clear Ask**：关闭限价卖单挂单
- **Clear All**：关闭所有限价挂单
- **Close**：平仓 / 关闭所有订单
- **反向交易**：平仓同时，自动下反向市价单

**订单有效期**
- **GTC**（Good Till Cancelled）：订单一直有效，**必须手动平仓**，否则永久存在
- **Day**：当天有效，美国市场收盘后**自动平仓所有单**（含浮动盈亏、限价单）

**账户选择**
- `Demo`：软件自带模拟账户
- 下方：实盘期货账户（需提前开户并连接）

### 6.3 退出策略（自动止盈止损）
- 点击 ▲ 打开设置 → 选择策略类型（最常用：**固定止盈止损**）
- 示例：止盈 30 Tick，止损 10 Tick
- 特性：
  - 下**市价单**成交后，自动挂上止盈止损
  - 下**限价单**成交后，才会显示并挂上止盈止损
  - 可手动拖动止盈止损价位调整
  - 平仓后，对应的止盈止损自动取消

### 6.4 图表交易
- 默认关闭，可开启后在 K线图上点击 `Buy` / `Sell` 下单
- 操作较麻烦，一般不使用

## 第七期：软件设置详解

### 7.1 布局设置
- **作用**：保存多套模板布局，实现**瞬间切换**，满足不同交易场景
- **路径**：设置 → 布局设置 → 添加 → 命名 → 加载所需模板 → 调整位置 → 保存
- 切换时直接点击已保存的布局名称即可

### 7.2 主题
- **黑色**（默认）/ **白色**（亮度）
- 白色较晃眼，建议保持黑色

### 7.3 声音设置
- 系统默认连接/断开等提示音
- 可自定义替换（**必须为 `.wav` 格式**）

### 7.4 热键（快捷键）
- 路径：主页 → 设置 → **热键**
- 可自定义所有功能快捷键
- **推荐设置**：平仓设为 **回车键**，实现快速平仓

### 7.5 时区（时差）
- 默认显示 **纽约时间**
- 可改为 **本地时区 / 北京时间**（根据交易所选择 `+8` 或点击「本地市区」）

### 7.6 交易手续费设置
- 根据实际开户情况设置各品种手续费
- 示例：CME 微型标普 `M1` 单面 **0.49 美金**，一笔成本约 **0.98 美金**
- 设置后，交易统计中的盈亏数据更贴合实际

### 7.7 交易统计
- 路径：模拟账户 → 订单 / 交易 / 统计数据 / 日志 / 盈亏曲线
- 可查看总笔数、多头/空头笔数、逐笔盈亏、盈亏曲线等

### 7.8 高级与备份
- **高级设置**：保持默认，勿随意改动
- **数据库备份天数**：默认 5 天，最大 4 天（**不建议改大**，非常占内存）

## 第八期：订单轨迹模板指标详解

### 8.1 K线主体元素

| 元素                  | 含义                                                         | 设置/说明                         |
| --------------------- | ------------------------------------------------------------ | --------------------------------- |
| **POC 显示**          | 每根 K线 Bid/Ask 的成交量分布显示                            | —                                 |
| **红色加粗数字**      | **十倍失衡**：超过上一个价位斜对角 10 倍以上成交             | 右键 → 集群设置 → 失衡 → 阈值调整 |
| **蓝色/红色箭头**     | **反转信号**：根据 Delta 判断，蓝色向下=可能反转跌，红色向上=可能反转涨 | 可作为进场参考信号                |
| **中间虚线**          | **VWAP**（日级别）：交易量加权均线，每天根据昨日行情自动绘制 | 重要参考依据                      |
| **蓝色横线（细）**    | **3倍卖方失衡**：连续 3 个价位，卖方成交量是买方 3 倍以上    | 潜在压力位                        |
| **蓝色横线（粗）**    | **5倍卖方失衡**：连续 4-5 个价位，卖方成交量是买方 5 倍以上  | 强压力位                          |
| **红色横线（细/粗）** | **3倍/5倍买方失衡**                                          | 潜在支撑位                        |
| **蓝色/红色圈**       | **大额异常交易识别**：蓝=主动卖方暴力吃掉被动买方；红=主动买方暴力吃掉被动卖方 | 系统自动识别，效果较好            |
| **上下数字**          | **比率指标**：一般用不到                                     | 可忽略                            |

### 8.2 下方信息区

| 元素                 | 含义                                                         |
| -------------------- | ------------------------------------------------------------ |
| **灰色方块**         | **交易量**：当前 K线时间周期内的总成交手数（如 5分钟 K线 = 5分钟总成交量），数据来自 CME/COMEX 实时交易所数据 |
| **红蓝柱体（蜡烛）** | **Delta 差值可视化**：直观显示每根 K线多空力量差             |
| **下方表格**         | Ask/Bid 具体成交量、Delta 值、Max Delta、Min Delta、Delta 变化百分比 |
| **右下角倒计时**     | 当前 K线周期剩余时间（如 5分钟 K线显示剩余多少秒收盘）       |

### 8.3 右侧能量条
- **上方蓝色**：Ask 限价卖单挂单量 → 显示**抛压**强度
- **下方红色**：Bid 限价买单挂单量 → 显示**支撑**强度
- 通过长短判断各价位的挂单密集度（需付费深度数据才能看到完整档位）

## 第九期：市场深度（DOM）与交易量分布详解

### 9.1 市场深度（DOM）各列含义

| 列                      | 颜色/位置  | 含义                                                         |
| ----------------------- | ---------- | ------------------------------------------------------------ |
| **价格**                | 最左列     | 实时期货报价（来自 CME 等交易所）                            |
| **Bid**                 | 蓝色背景列 | **限价买单**实时挂单数（Tag 级别），代表做多意图或平空单意图 |
| **蓝色数字**（Bid 旁）  | 蓝色       | **主动卖方**成交被动 Bid → **空头动能**                      |
| **红色数字**（Bid 旁）  | 红色       | **主动买方**成交被动 Ask → **多头动能**                      |
| **Ask**                 | 列         | **限价卖单**实时挂单数                                       |
| **Sell**                | 列         | **主动卖方**成交被动买方 → 当天各价位累计成交总量            |
| **红色数字**（Sell 旁） | 红色       | **主动买方**成交被动卖方 → **多头动能**                      |
| **总量**                | —          | 每个价位当天的总成交量                                       |

> **期货交易规则提醒**：期货不可锁仓。下反向单会直接平仓，而非像 MT4 那样形成锁单。

### 9.2 右侧交易量分布

| 元素                    | 含义                                                         |
| ----------------------- | ------------------------------------------------------------ |
| **各价位成交量柱**      | 当天每个 Tag 级别的具体成交量，判断买卖双方大量成交的价位（POC 区域） |
| **成交量缺口**          | 成交量少的价位 = **潜在压力/支撑位**                         |
| **蓝色虚线**            | **日级别 VWAP**                                              |
| **蓝色/红色箭头**       | 根据 Delta 判断的实时反转信号（与订单轨迹联动）              |
| **红蓝蜡烛图**          | **吉利 Delta**：零轴之上看多，零轴之下看空                   |
| **黄色柱体**            | **波动率+交易量一体指标**：当某根 K线的交易量与波动率远大于之前 K线时显示黄色（突破黑色均线） |
| **淡蓝色横线**          | **15分钟级别 POC 控制点**                                    |
| **R1 / R2**             | **第一/第二压力位**（根据昨天行情自动绘制）                  |
| **PP 点**               | **枢轴点**：根据昨天行情自动识别的关键价位                   |
| **S1 / S2 / S3**        | **第一/第二/第三支撑位**                                     |
| **白色短线（Account）** | **日级别 POC**：当天交易量最大的价位                         |
