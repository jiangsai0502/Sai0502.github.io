## 1. 总结先说

过去这些回测可以分成两类口径：

1. 早期 5m 级别回测：结果很好，但偏理想化。
2. 后期更接近实盘的回测：加入 1m 执行、手续费、禁止交易时段、日内亏损熔断、wave update 后，结果明显变差。

最重要的结论是：

- 早期 `0.618 挂单入场 / 止损波段起点 / 止盈波段终点` 在 5m 回测里 360 天净利润 `+$14,820.32`，PF `1.30`，但这个结果不能直接当作实盘预期。
- 一旦改成 `5m 产生信号、1m 执行进出场`，同样的核心策略 360 天变成亏损：Loose `-$6,158.41`，Strict `-$7,163.76`。
- 推保总体是负贡献。`23.6% 推保` 和 `50% 推保` 都明显压低胜率和收益。
- 1m 吞没入场没有改善结果，长期看反而更差。
- `wave update + -0.27 TP` 是目前所有更现实口径里最接近可研究的方向。
- 加上日内亏损熔断后，360 天最好的组合是 `Loose + 0.618 limit + SL waveStart + wave update + TP -0.27 + 不推保`，净利润 `+$1,234.38`，PF `1.02`，最大回撤 `-$4,906.53`。
- 这个最佳结果也只是勉强接近正期望，不够强，不足以支持“放心自动化实盘”。

一句话版本：

> 当前策略的结构识别有价值，但裸信号质量不够。真正有希望的方向不是继续加推保或更近止盈，而是增加行情过滤条件，比如大周期方向、流动性扫荡衰竭、时间段、波动率、消息行情过滤。

### 2.2 后期更现实的统一假设

后面几轮回测逐步采用这些实盘假设：

- 合约：MGC，1 手。
- 点值：MGC 约 `$10/point`。
- 手续费：买 `$2`，卖 `$2`，一笔完整交易 `$4`。
- 禁止新开仓时段：北京时间 `04:00-07:00`。
- 日内熔断：北京时间 `07:00 -> 次日 04:00` 算一个交易日，单日已实现亏损达到 `-$300` 后，当天不再开新仓。

- 最大回撤是权益曲线从峰值到后续低点的最大回撤，不是单日最大亏损。

## 5. 按影响条件拆解

### 5.1 5m 回测 vs 1m 执行

影响最大。

早期 5m 口径：

- 360 天净利润 `+$14,820.32`
- PF `1.30`
- 最大回撤 `-$1,480.59`

1m 执行口径：

- Loose 原始版本 360 天 `-$6,158.41`
- Strict 原始版本 360 天 `-$7,163.76`

解释：

- 5m K 线内部到底先碰 TP、先碰 SL、是否先回调到 0.618，都会影响结果。
- 早期回测对 5m 内部路径做了简化，因此对这个策略过于乐观。
- 以后只应该相信 1m 执行，甚至更细粒度的 tick / order book 口径。

### 5.2 手续费

手续费设为每笔 `$4` 后，对高频策略影响很明显。

这个策略 360 天通常有 1,500 到 2,600 笔交易。  
如果 2,000 笔交易，一年手续费就是：

```text
2,000 * $4 = $8,000
```

这解释了为什么早期看似有优势的策略，在实盘口径里很容易被手续费吃掉。

### 5.3 禁做时段：北京时间 04:00-07:00

加入禁做时段后，策略更贴近你的实际要求。  
这个条件主要作用不是提高单笔胜率，而是减少不想交易的时段暴露。

目前看，它不是让策略从亏变赚的核心因素，但它是必要风控条件。

### 5.4 日内亏损熔断

日内熔断是有效的。

对 `Loose + limit + -0.27 TP + 不推保`：

| 版本 | 360 天净利润 | PF | 最大回撤 |
|---|---:|---:|---:|
| wave update，无日内熔断 | +$441.77 | 1.01 | -$8,076.32 |
| combo daily circuit，有日内熔断 | +$1,234.38 | 1.02 | -$4,906.53 |

结论：

- 熔断改善了最大回撤。
- 它也略微改善净利润。
- 但熔断不是信号过滤，它只是停止连续亏损日继续交易。
- 如果信号本身没有优势，熔断只能减伤，不能创造稳定正期望。

### 5.5 Loose vs Strict

直觉上 Strict 应该更强，因为它要求实体更严格突破。  
但回测结果不支持这个直觉。

360 天几个核心对比：

| 策略 | Loose 净利润 | Strict 净利润 | Strict - Loose |
|---|---:|---:|---:|
| 1m 执行原始 TP/SL | -$6,158.41 | -$7,163.76 | -$1,005.35 |
| wave update + TP -0.27 | +$441.77 | -$82.78 | -$524.55 |
| daily circuit + limit + TP -0.27 + no BE | +$1,234.38 | -$241.00 | -$1,475.38 |
| TP 0.236 limit 版本 | -$6,930.19 | -$7,629.81 | -$699.62 |

结论：

- Strict 确实减少了一部分交易。
- 但它过滤掉的不只是坏交易，也过滤掉了不少好交易。
- 对这个策略来说，突破后能不能延续，不只取决于实体是否突破结构点。
- Strict 不能单独作为提高胜率的核心过滤器。

### 5.6 推保：23.6% vs 50%

推保整体是负贡献。

早期 5m 版本已经能看出：

| 推保方式 | 360 天净利润 | PF | 胜率 |
|---|---:|---:|---:|
| 不推保 | +$14,820.32 | 1.30 | 43.45% |
| 23.6% 推保 | -$2,549.16 | 0.95 | 30.45% |
| 50% 推保 | -$377.02 | 0.99 | 22.80% |

后期更现实口径也类似。

结论：

- 23.6% 推保太早，会把大量正常波动中的单子踢出。
- 50% 推保比 23.6% 好一点，但仍然压缩收益。
- 当前策略不是“推保能救”的问题，而是入场质量和行情过滤不够。

### 5.7 TP waveEnd vs TP -0.27

`-0.27 TP` 明显优于 `waveEnd TP`。

在日内熔断组合里：

| 策略 | 360 天净利润 | PF | 最大回撤 |
|---|---:|---:|---:|
| Loose limit + TP waveEnd + no BE | -$3,461.73 | 0.95 | -$8,399.12 |
| Loose limit + TP -0.27 + no BE | +$1,234.38 | 1.02 | -$4,906.53 |

结论：

- `waveEnd` 作为止盈太近或太容易被结构噪音影响，无法覆盖亏损。
- `-0.27` 给了盈利单更大空间，是目前最有价值的盈利端修改。
- 但是 `-0.27` 会降低胜率，所以必须配合更好的过滤。

### 5.8 TP 0.236

0.236 是失败方向。

它提高了胜率，但盈亏结构太差：

- Loose limit 版本胜率 `48.68%`
- 但净利润 `-$6,930.19`
- PF 只有 `0.89`

结论：

- 近止盈不是答案。
- 这个策略需要抓到相对大的推动段，而不是频繁吃小段。

### 5.9 Limit 入场 vs 1m 吞没入场

Limit 入场整体优于 1m 吞没入场。

在日内熔断 + TP -0.27 + no BE 下：

| 入场方式 | 360 天净利润 | PF | 胜率 |
|---|---:|---:|---:|
| Loose limit | +$1,234.38 | 1.02 | 30.63% |
| Loose engulf | -$1,990.78 | 0.96 | 44.00% |

结论：

- 1m 吞没提高了胜率，但牺牲了入场价格和盈亏比。
- 胜率不是问题核心，盈亏比和位置更重要。
- 0.618 limit 的价格优势，目前比吞没确认更有价值。

### 5.10 1m MSS 入场

1m MSS 入场效果不好。

360 天：

| 策略 | 净利润 | PF |
|---|---:|---:|
| Loose 1m MSS，TP 前波段点 | -$10,199.00 | 0.41 |
| Strict 1m MSS，TP 前波段点 | -$9,805.00 | 0.41 |
| Loose 1m MSS，TP -0.27 | -$6,146.49 | 0.89 |
| Strict 1m MSS，TP -0.27 | -$6,119.79 | 0.89 |

结论：

- 1m MSS 作为入场确认没有显著提高信号质量。
- 它可能把入场拖晚，牺牲 R 值。
- 如果继续研究 1m 结构，应该不是简单等 1m MSS，而是定义更完整的 1m liquidity sweep + displacement + FVG / OB 类型过滤。

## 6. 最值得保留的候选基线

目前最值得继续研究的是：

```text
Break mode: Loose
Entry: 0.618 limit
SL: 5m waveStart
TP: 5m Fib -0.27
Wave update: enabled
Breakeven: disabled
Blocked new entry: Beijing 04:00-07:00
Daily circuit: stop new entries after -$300 realized loss per Beijing trade day
Commission: $4 round trip
```

360 天结果：

| 指标 | 数值 |
|---|---:|
| 交易数 | 1,665 |
| 胜率 | 30.63% |
| 净利润 | +$1,234.38 |
| PF | 1.02 |
| 最大回撤 | -$4,906.53 |

这个结果只能说明：

- 方向比其他组合好。
- 它接近正期望。
- 但优势太薄，不能直接自动化实盘。

## 7. 明确不建议继续作为主线的方向

### 7.1 固定 0.236 止盈

原因：

- 胜率上来了，但利润空间太小。
- 手续费和亏损单足够吃掉所有优势。

### 7.2 早推保

原因：

- 23.6% 推保破坏最大。
- 50% 推保也没有真正改善长期收益。

### 7.3 简单 1m 吞没确认

原因：

- 它不是有效过滤器。
- 它可能让入场变晚，降低 R 值。

### 7.4 简单 1m MSS 确认

原因：

- 前波段点止盈版本 PF 只有 `0.41`。
- -0.27 TP 版本也仍然明显亏损。

## 8. 为什么 Strict 没有更好

从代码和策略两方面看：

### 8.1 代码层面

Strict 主要限制的是“突破确认方式”：

- Loose 更宽松。
- Strict 要求实体收线突破，并且如果之前有影线扫过，后续实体还要越过影线极值。

这会减少一部分假突破，但也会造成两个副作用：

- 入场信号变少。
- 进入趋势早期的机会被过滤掉。

### 8.2 策略层面

对这个策略来说，赚钱的关键不是“突破是否足够漂亮”，而是：

- 突破前是否已经扫过足够流动性。
- 推动段是否还没衰竭。
- 是否顺更大周期方向。
- 回调到 0.618 后是否仍然有足够空间打到 -0.27。
- 交易时段是否有足够波动。

Strict 只解决了其中很小一部分，所以不能显著提高结果。

## 9. 下一步真正应该研究的过滤条件

当前不是继续微调 TP/SL 的阶段，而是应该定义“哪些结构突破值得做”。

建议下一步重点研究：

### 9.1 大周期方向过滤

可以定义为：

- 只做 15m / 1h 方向一致的 5m 信号。
- 或者 5m 做单方向必须与 15m 最近一次 MSS/BOS 方向一致。
- 或者价格必须在 15m premium/discount 合理区域内。

目标：

- 减少逆大周期的 5m 结构突破。
- 避免在大周期震荡中间频繁交易。

### 9.2 流动性扫荡后衰竭过滤

可以尝试定义为：

- 最近 N 根 K 线连续扫高/扫低，但实体推进不足。
- 突破段越来越长，但收线推进越来越弱。
- 大实体消息 K 后，后续进入宽幅震荡，不再追结构。
- 连续 sweep 后没有 displacement，则不做。

目标：

- 过滤掉看似 MSS/BOS、实际已经消耗完动能的行情。

### 9.3 时间段过滤

目前只排除了北京时间 04:00-07:00。  
后面可以按交易时段分组统计：

- 亚洲盘
- 伦敦前后
- 纽约开盘
- 纽约午盘
- 数据公布前后

目标：

- 找出哪些时间段的 MSS/BOS 有正期望。
- 禁止明显亏损时间段。

### 9.4 波动率过滤

可以测试：

- ATR 太低不做。
- 单根 5m K 线过大不做或切换到内部 1m 结构。
- 当前推动段过长不追。
- 0.618 到 SL 的距离超过某个阈值不做。

目标：

- 过滤手续费占比过高的小波动。
- 过滤止损过大的消息行情。

### 9.5 R 值过滤

对每一笔交易，入场前计算：

```text
R = abs(TP - Entry) / abs(Entry - SL)
```

建议测试：

- R < 1.2 不做
- R < 1.5 不做
- R < 2.0 不做

目标：

- 保证即使胜率不高，也有足够盈亏比覆盖亏损。

## 10. 最终结论

当前已经测出来的事实是：

1. 单纯 5m MSS/BOS 结构突破，不足以直接自动化。
2. 早期 5m 回测利润很高，但更现实的 1m 执行后变成亏损。
3. 推保不是解法。
4. 0.236 近止盈不是解法。
5. 简单 1m 吞没和简单 1m MSS 不是解法。
6. `wave update + -0.27 TP + 日内熔断` 是目前最接近可用的方向。
7. 但最优 360 天结果也只有 `+$1,234.38`，PF `1.02`，优势太薄。
8. 下一步应该做的是过滤条件，而不是继续小改止盈止损。

建议把下一轮回测的主线定为：

```text
Loose
0.618 limit entry
SL waveStart
TP -0.27
No breakeven
Wave update
Daily loss circuit
+ 大周期方向过滤
+ 流动性扫荡/衰竭过滤
+ R 值过滤
+ 时间段过滤
```

只要这些过滤条件能把交易数明显降下来，同时保住主要盈利单，这个策略才可能从“勉强接近正期望”变成“值得小仓实测”。
