#### 1. 背景分类（GC F5）

| 背景            | 特征                                  | 操作倾向                   |
| --------------- | ------------------------------------- | -------------------------- |
| **强趋势**      | 单边运行，K线实体大，几乎无回调       | 顺势做，不吃第一次回调     |
| **弱趋势/震荡** | 有来有回，K线上下影线多，在区间内波动 | 高抛低吸，在显著区边缘接针 |
| **低波动率**    | K线很小，成交量萎缩                   | 观望，不轻易入场           |

> **周期选择**：黄金主要看 **F5、F30、H1**。F30/H1找显著区,F5 入场

#### 2. 找显著区（LRZ）（4种方式）

* **什么是显著区？**

  > **显著区 = 逻辑反转区（Logic Reversal Zone）= 关键位**

  - **唯一目的**：**提供入场点位**。不是为了看结构，不是为了分析，就是为了"在这里下单"。
  - **本质**：资金真金白银堆积、多空曾经激烈博弈的区域。
  - **有效性**：强显著区是长期有效的；弱显著区是临时用来验证逻辑、作为止损或入场参考的。

* **强/弱显著区**

  | 类型         | 特征                                         | 有效期                       |
  | ------------ | -------------------------------------------- | ---------------------------- |
  | **强**显著区 | 大单密集、多空激烈博弈、多次验证过的区域     | 长期有效，可一直标注在图表上 |
  | **弱**显著区 | 临时找到的、用于验证当前逻辑是否证伪的小区域 | 临时使用，作为入场或止损参考 |

* **方式1：LRZ-BZ多空博弈区（最核心）**

  * **识别**

    * **纵轴**：单量单量越大越显著（GC ≥100 手需重点关注）
    * **横轴**：单 K 内部或几根 K 线聚合后，正负 Delta 都很突出
      * 某一价位**既有大量主动买单，又有大量主动卖单**

    ![image-20260803103406119](https://raw.githubusercontent.com/jiangsai0502/PicBedRepo/master/img/202608031034187.png)

  * **原理**

    * 这个价格区域多空都认可，是"战场"
    * 价格再次回到这里时，之前被套的一方会想办法解套，形成推力

* **方式2：cuz小丑解套区**

  * **小丑**：被套的单子。他们止损或平仓时，会助推价格向相反方向运动。
  * **识别**
    * **看 Delta**：某一价位有**极大的正/负 Delta**（例：多头趋势）
      * **负 Delta**：被套空单，价格回来，空头解套，相当于买入
      * **正 Delta**：多头成本区，价格回来，多头保护成本底线，再次买入
    * **看大单**：独立大单（100+ 手）出现的位置

* **方式3 & 4：情绪失衡区**

  ![image-20260803110250844](https://raw.githubusercontent.com/jiangsai0502/PicBedRepo/master/img/202608031102882.png)

  * **方式3：情绪失衡区**
    * **识别**
      * K 线很长，有速度、有成交量、有大单，快速离开某个区域
      * 大单之间有缺口，即失衡
      * 表明一方完全主导，情绪极端
    * **用法**
      * 情绪区域的**起点** = 关键位（主力发力的位置）
      * 当价格**跌破**情绪区域起点 → 可能反转
      * 情绪区域本身 = 强支撑/阻力
  * **方式4：情绪过渡区**
    * **识别**
      * 大 K 线试图往下/往上冲，但被**被动订单**给**吸收**了，收成长影线
    * 用法
      * 等下一根 K 线确认方向
        * 如果验证成功（比如下影线后收看涨吞没），则该区域成为关键位；
        * 若验证失败（比如下影线后收看跌吞没），压刺

#### 3. 入场

* **左侧入场（接针 / 挂单）**
  * **用法**
    * 在显著区外侧一点挂单，止损在在**被套单子（小丑）的另一侧**
    * **挂单位置**：在显著区的**被套单子（小丑）的外侧多出一点**（防止接不到）
    * **止损位置**：在**被套单子（小丑）的另一侧多出一点**
    * **盈亏比**：通常做 **1:1**
  * **风险**：可能被直接击穿
  * **对策**：最多"复仇"一次，连续打损两次就停止，说明趋势可能延续
* **右侧入场（突破后追单）**
  - **验证显著区有效性**：第1次打到显著区时不入场，如果能撑住，则表明有效
  - **入场**
    - **被套的单子（小丑）** + **反包** + **反向放量**（比如在多头显著区出**空头吸收** + **看涨吞没** + **阳K放量**）
    - **Delta 极端值**：比如某根 K 线出现 -168 手 Delta，说明空头极强
    - **大单（泡泡）**：机构真金白银进场的位置
    - **反包 K 线**：阴线后立刻被阳线吞没，且伴随 Delta 转正

#### 4. 止损：安全垫与小丑

* **核心原则**

  > **止损不是随意放的，而是放在"逻辑被证伪"的位置。**

  | 情况           | 止损位置         | 含义                                              |
  | -------------- | ---------------- | ------------------------------------------------- |
  | **左侧接针**   | 最近的小丑区外侧 | 如果价格击穿小丑区，说明反向力量极强，原逻辑错误  |
  | **右侧追单**   | 显著区外侧       | 如果突破失败、回到原区域，说明是假突破            |
  | **强趋势追单** | 最近的显著区外侧 | 既然认为趋势强，就不应回调太深，深回调 = 趋势不强 |

* **安全垫**

  * 如果两个显著区距离很近，连续突破两个关键位的难度很大
  * **止损放第 1 个显著区（小丑区）外侧**：更近，但可能被插针扫损
  * **止损放第 2 个显著区外侧**：更远，胜率更高，但止损较大

#### 5. 实战推演（GC）

**Step 1：找显著区**
- 在图表上找到**放量、大单、Delta 极端**的区域
- 用矩形标出这些"战场"

**Step 2：等待价格到达**
- 价格从远处向显著区运动
- 观察是第一**次测试**还是**二次测试**

**Step 3：判断反应**
- **第一次测试**：通常不入场（尤其是逆势），或极小仓位试单
- **第二次测试**：如果第一次起反应了，第二次回踩显著区时入场胜率更高

**Step 4：选择方向**
- 如果显著区**在下跌趋势中**，且出现**多头被套 + 空头放量** → 继续做空
- 如果显著区**被向上突破**，且出现**空头被套 + 多头放量** → 反手做多

**Step 5：吃利润**
- 一段趋势中**不要从头吃到尾**
- 在显著区之间**分段吃**：A→B 吃一段，B→C 吃一段
- 每段目标通常是 **1:1**

### 6.2 关键细节

| 细节                       | 说明                                                 |
| -------------------------- | ---------------------------------------------------- |
| **第一次回调不做**         | 强趋势中的第一次回调不参与，等二次确认               |
| **震荡市中边缘做**         | 价格在两个显著区之间震荡时，只在边缘挂单，不在中间做 |
| **有反应就留，没反应就走** | 进场后如果价格在成本区晃荡，说明"不强"，先平仓观望   |
| **突破后看是否站稳**       | 突破显著区后，要看实体是否收在外面，还是影线假突破   |

## 七、品种差异：黄金 vs NQ（纳斯达克）

| 对比项       | 黄金（GC）                     | 纳斯达克（NQ）                     |
| ------------ | ------------------------------ | ---------------------------------- |
| **适用性**   | ✅ **非常适合**，显著区精准有效 | ⚠️ **不太适用**，假突破多，容易被扫 |
| **波动特征** | 相对规律，关键位反应明确       | 波动剧烈，插针频繁                 |
| **止损设置** | 可以放在小丑区外侧             | 止损容易被猎杀                     |
| **建议**     | 主做黄金/ES                    | NQ 需结合热图、DOM，且要更谨慎     |

> **建议**：先以 **黄金** 练习这套逻辑，熟练后再考虑 ES，NQ 需要额外的工具和认知。

## 八、核心心法

1. **显著区只有一个目的：入场。** 不要把它搞复杂，就是为了知道"在哪里下单"。
2. **先判断背景，再找关键位。** 不知道趋势还是震荡，就不要开仓。
3. **左侧是赌，右侧是确认。** 新手先做右侧，熟练后再做左侧接针。
4. **小丑是你的朋友。** 被套的单子止损/平仓时，会帮你推价格。
5. **不要吃到顶底。** 一段行情分几段吃，每段 1:1 足矣。
6. **不强就走。** 进场后价格不立刻走，说明力量不够，先离场。
7. **验证过的关键位才可靠。** 第一次测试谨慎，第二次测试大胆。
8. **黄金练手，NQ 慎做。** 这套系统的灵魂在黄金上最能体现。

## 九、工具使用建议

| 工具                    | 用途                            | 设置要点                             |
| ----------------------- | ------------------------------- | ------------------------------------ |
| **足迹图（Footprint）** | 看单根 K 线内部的 Delta、成交量 | 关注 100+ 手的独立大单，看对角线失衡 |
| **Delta 分布图**        | 找出累计 Delta 最大的价位       | 拉水平线看正负 Delta 的博弈区域      |
| **热图（Heatmap）**     | 看大单泡泡、冰山订单、流动性池  | 观察关键位是否有机构挂单             |
| **挂单指标（Bookmap）** | 看盘口深度、被动订单分布        | 识别真假突破、冰山订单               |
